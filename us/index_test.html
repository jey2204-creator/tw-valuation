手機、電腦都開同步後，改主題會自動存到你 GitHub 帳號的一個秘密 Gist，另一台開頁或切回來時就會抓到。每個瀏覽器（含加到主畫面的 App）各貼一次 token。

產生 token：GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token，只勾 gist，Expiration 選 90 days。

token 只存在這個瀏覽器、只送到 api.github.com。Gist 裡只有主題設定；這個 token 讀寫得到你全部的 Gist，所以別在 Gist 放敏感資料。手機遺失就到 GitHub 撤銷 token。
